# @luminalearn/validator

Bộ kiểm tra và xác thực dữ liệu khoa học:
- Kiểm tra tính hợp lệ và logic của các định luật, công thức, số liệu khoa học
- Đảm bảo scene schema không chứa giá trị mâu thuẫn trước khi tiến hành render
- Cơ chế feedback tự động lại cho Gemini Agent khi phát hiện lỗi dữ liệu
