## 3. Những lỗi logic đã sửa

1. **Lỗi che lấp Maturity của Capability chưa có Adapter (Precedence Masking):**
   - *Hiện tượng cũ:* Trong `resolveVisualCapabilityV1`, kiểm tra validation chạy trước kiểm tra `readinessStatus`. Khi một capability có `readinessStatus: 'planning_only'` (như Bayes / `probability_tree` hoặc `geometry_2d`) được yêu cầu với `availableValidation: []`, resolver trả về mã `visual_validation_missing` với status `needs_review`. Sau đó `universal-educational-director-v3.ts` gán readiness là `needs_review` thay vì `planning_only`.
   - *Đã sửa:* Đưa kiểm tra `capability.readinessStatus !== 'render_ready'` lên trước. Khi capability là `planning_only`, nó luôn trả về `visual_adapter_not_ready` và bảo toàn trạng thái `planning_only`.
2. **Lỗi thiếu Primitives hình học trong Visual DSL Renderer:**
   - *Hiện tượng cũ:* Visual DSL scene chỉ hỗ trợ `point`, `vector`, `arrow`, nhưng thiếu `segment`, `polygon`, `shape`, `highlighted_region`, khiến việc vẽ hình học 2D hoặc biểu diễn diện tích bị chặn bởi unsupported primitive check.
   - *Đã sửa:* Đã bổ sung đầy đủ schemas, types và renderers trong SVG và HTML canvas.
3. **Lỗi thiếu Dynamic Numeric Labels trên Đồ thị:**
   - *Hiện tượng cũ:* Đường tiếp tuyến và chuyển động cát tuyến chỉ vẽ đường line mà không có nhãn số học động phản ánh giá trị đạo hàm hoặc trạng thái hội tụ tại frame hiện tại.
   - *Đã sửa:* Đã bổ sung dynamic numeric labels hiển thị $f'(x_0) = \text{slope}$ và nhãn tiến trình cát tuyến.
