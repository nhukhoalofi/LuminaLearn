## 1. TỔNG QUAN VÀ MỤC TIÊU PHASE 10.1

Phase 10.1 là đợt triển khai hiệu chỉnh mục tiêu (targeted corrective implementation) nhằm giải quyết dứt điểm toàn bộ các khiếm khuyết được phát hiện trong quá trình đánh giá độc lập mã nguồn Phase 10:

1. **P0-01 (Lỗi ManimPango Build trên CI GitHub Actions):** Tách rời phụ thuộc kiểm định toán học SymPy (nhẹ, thuần Python) khỏi phụ thuộc kết xuất Manim (nặng, yêu cầu thư viện hệ thống Cairo/Pango C-libraries). Đảm bảo CI chạy `ci.yml` kiểm định toán học với SymPy không bao giờ vấp phải lỗi biên dịch ManimPango.
2. **P0-02 (Lỗ hổng bao phủ chứng minh toán học trong Visual DSL):** Bổ sung chính sách nội dung toán học tường minh `MathContentPolicySchema` (`'formal_verified' | 'illustrative_unverified' | 'conceptual'`). Cấm tuyệt đối công thức hoặc đồ thị chưa được kiểm định SymPy xuất hiện trong các phân cảnh chứng minh hình thức (`algebra_identity`, `formula_derivation`, `proof_step`).
3. **P1-01 (Đồng bộ ngữ cảnh tin cậy giữa video ngắn và video dài):** Xây dựng hàm nguồn chuẩn `deriveTrustedProofContextV3(artifact)` và truyền `trustedProofContext` đồng nhất trong cả hai tiến trình kết xuất `pipeline-v3.ts` (video ngắn 35s/60s) và `longform-renderer-v3.ts` (video dài phân đoạn), bảo đảm huy hiệu "✓ SymPy Verified" hiển thị chính xác trên toàn hệ thống.
4. **P1-02 (Lưu trữ và khử nhiễm Visual DSL trên Teacher Studio):** Cập nhật `V3TeacherStudio.tsx` và API route `PATCH /api/v3/lessons/[lessonId]/draft` để truyền `visualDefinitions`, đồng thời loại bỏ toàn bộ binding tin cậy do client tự phong trước khi gửi về máy chủ.
5. **P1-03 (Bảo toàn toàn vẹn dữ liệu bộ nhớ đệm Preview):** Bổ sung `contentHash` (SHA-256) vào `CacheEntryMeta`, xác thực kích thước và băm nội dung khi đọc cache và khi phục hồi sau khởi động lại; phân lập tuyệt đối trạng thái bộ nhớ đệm theo thư mục.
6. **P1-04 (Ràng buộc kiến trúc xác thực & Dọn dẹp bộ nhớ):** Ghi rõ tài liệu ràng buộc single-process của `AuthStore`, tự động dọn dẹp các lần thử đăng nhập và phiên làm việc đã hết hạn để chống rò rỉ bộ nhớ/tệp tin; kiểm tra `process.env.LUMINA_TRUST_PROXY === 'true'` trước khi xử lý `X-Forwarded-For`.
7. **P1-05 (Hiệu chỉnh tài liệu kỹ thuật Phase 10):** Sửa các sai lệch tài liệu về TTL phiên làm việc (8 giờ thay vì 24 giờ) và giới hạn tần suất đăng nhập (theo tên người dùng thay vì IP).

## 3. CHI TIẾT CÁC THAY ĐỔI CỐT LÕI

Trong `services/math-engine/pyproject.toml`:
```toml
dependencies = [
    "sympy>=1.13,<2",
]

[project.optional-dependencies]
rendering = [
    "manim>=0.19,<0.23",
]
test = [
    "pytest>=8.0",
]
all = [
    "manim>=0.19,<0.23",
    "pytest>=8.0",
]
```
- **Lợi ích:** GitHub Actions CI (`.github/workflows/ci.yml`) chạy bước `pip install -e services/math-engine[test]` chỉ tải SymPy và Pytest, hoàn thành trong dưới 10 giây và không bao giờ gặp lỗi thiếu C-compiler hay `ManimPango`.
- Quy trình kết xuất thực tế (`.github/workflows/render.yml`) được trang bị các gói hệ thống Ubuntu (`libcairo2-dev libpango1.0-dev pkg-config`) và cài đặt `services/math-engine[all]` cho tác vụ Manim.

### 3.2. Chính sách Nội dung Toán học & Ràng buộc Chứng minh Hình thức
Trong `packages/scene-schema/src/v3/visual-dsl.ts`:
```typescript
export const MathContentPolicySchema = z.enum([
  'formal_verified',
  'illustrative_unverified',
  'conceptual'
]);
export type MathContentPolicy = z.infer<typeof MathContentPolicySchema>;
```
Trong `packages/agent/src/orchestration/draft-manager-v3.ts`:
```typescript
const isFormalProofScene = definition.sceneType === 'algebra_identity' || definition.sceneType === 'formula_derivation';

// 1. Cấm công thức/đồ thị chưa kiểm định trong phân cảnh chứng minh hình thức
if (isFormalProofScene && (element.elementType === 'formula' || element.elementType === 'graph') && policy !== 'formal_verified') {
  throw new Error(`formal_proof_unverified_content_forbidden: Formal proof scene '${definition.sceneId}' cannot contain unverified ${element.elementType} '${element.elementId}'`);
}

// 2. Yêu cầu claimId cho các phần tử formal_verified
if (policy === 'formal_verified') {
  if (!element.claimId) {
    if (isFormalProofScene) {
      throw new Error(`formal_proof_missing_claim_id: Formal proof scene '${definition.sceneId}' element '${element.elementId}' is classified formal_verified but lacks claimId`);
    }
    return [];
  }
  // Xác thực chặt chẽ với SymPy và so khớp biểu thức render
  ...
}
```

### 3.3. Đồng bộ Ngữ cảnh Tin cậy Giữa Video Ngắn và Video Dài
Xuất khẩu hàm tiện ích độc lập trong `packages/hybrid-renderer/src/pipeline-v3.ts`:
```typescript
export interface TrustedProofContextV3 {
  artifactIntegrityVerified: true;
  approvedDraftVersion: number;
}

export function deriveTrustedProofContextV3(artifact: ApprovedRenderArtifactV3): TrustedProofContextV3 {
  return {
    artifactIntegrityVerified: true,
    approvedDraftVersion: artifact.approvedVersion
  };
}
```
Cả hai đường ống `runRenderPipelineV3` và `LongFormSegmentRendererV3` đều ghi trường:
```json
"trustedProofContext": {
  "artifactIntegrityVerified": true,
  "approvedDraftVersion": 7
}
```
vào tệp đầu vào Remotion `v3-input-props.json`, loại bỏ hoàn toàn hiện tượng video ngắn bị Remotion nhận diện nhầm là bản nháp chưa duyệt.

### 3.4. Bảo toàn Toàn vẹn Bộ nhớ đệm Preview
Trong `apps/web/src/server/preview-cache-manager.ts`:
- Mỗi mục lưu đệm tính mã băm SHA-256 của ảnh PNG:
  `contentHash = createHash('sha256').update(buffer).digest('hex')`
- Khi truy xuất (`get`) và khi nạp lại từ ổ cứng (`recoverFromDisk`), hệ thống so khớp cả độ dài byte lẫn mã băm SHA-256. Nếu tệp PNG bị chỉnh sửa trái phép dù giữ nguyên tiêu đề PNG 8-byte, mục đệm lập tức bị trục xuất và trả về an toàn `null` (cache miss).
- Trạng thái bộ nhớ đệm được quản lý theo bảng băm `statesByDir: Map<string, CacheState>` tách biệt tuyệt đối giữa các thư mục kiểm thử và tiến trình khác nhau.

### 2. Triển khai Thử nghiệm Trường học Có Kiểm soát (Controlled Private Pilot): **PENDING CI VERIFICATION / NO-GO FOR RELEASE**
- **Lý do:** Toàn bộ mã nguồn đã được sửa chữa và kiểm tra cục bộ đạt chuẩn. Tuy nhiên, theo nguyên tắc kỹ thuật an toàn cao nhất, việc bàn giao cho giáo viên thực tế chỉ được kích hoạt sau khi nhánh `feat/v3-phase10.1-final-integrity-ci-closure` được đẩy lên GitHub và toàn bộ chuỗi pipeline GitHub Actions chạy xanh hoàn toàn mà không có lỗi ManimPango.
- Sau khi GitHub CI hoàn tất xác nhận, trạng thái sẽ tự động chuyển thành **GO**.

### 3. Vận hành Công cộng Đại chúng (Public Production Deployment): **NO-GO**
- **Lý do:** Hệ thống xác thực và quản lý hàng đợi hiện tại được thiết kế tối ưu hóa cho mô hình máy chủ đơn tiến trình (single-process in-memory lock & local file state persistence).
- Để mở rộng cho hàng nghìn người dùng đồng thời trên môi trường đám mây công cộng, hệ thống cần nâng cấp tầng lưu trữ phân tán (Redis session store, PostgreSQL database, cụm kết xuất worker phân tán).
