# Tài liệu kỹ thuật - LuminaLearn

Thư mục này chứa tài liệu thiết kế hệ thống, kiến trúc luồng dữ liệu (Data Flow), đặc tả API và hướng dẫn phát triển cho các module trong dự án.

## Mục lục tài liệu
1. **Kiến trúc hệ thống (`architecture.md`)**: Luồng hoạt động giữa Web, Gemini Agent, Validator, Schema và Remotion Worker.
2. **Quy chuẩn Schema (`schema-spec.md`)**: Cấu trúc Scene JSON contract cho việc sinh video.
3. **Hướng dẫn đóng góp (`contributing.md`)**: Quy tắc viết mã nguồn và đóng góp cho monorepo.
