# Tổng Riemann và Tích phân Xác định

## Ý tưởng xấp xỉ diện tích
Để tính diện tích hình thang cong giới hạn bởi parabol f(x) = x^2 trên đoạn [0, 1], ta chia đoạn [0, 1] thành n hình chữ nhật có độ rộng delta x = 1/n.

## Hội tụ tích phân
Khi tăng số hình chữ nhật n từ 4 lên 8 rồi 16, tổng diện tích các cột dần khít với đường cong cong.
Khi n tiến ra vô cực, tổng Riemann hội tụ chính xác về giá trị tích phân xác định bằng 1/3.
